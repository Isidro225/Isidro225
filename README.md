## Proyectos destacados

Catálogo online para un comercio de La Plata.

- Carrito y gestión de pedidos.
- Panel de administración e importación de productos.
- Tecnologías: Next.js, Tailwind CSS, PostgreSQL, Prisma y Cloudinary.

[Visitar sitio](https://alsedolorenzo.com)

### 📅 Bby Nails — Sistema de turnos
Aplicación para gestionar reservas y servicios de un salón de uñas.

- Reservas online con pago de seña mediante Mercado Pago.
- Calendario administrativo y gestión de clientes.
- Organización de turnos por empleado.
- Tecnologías: Next.js, React, PostgreSQL y Prisma.
