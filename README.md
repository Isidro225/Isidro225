## 🚀 Proyectos destacados

### 🛒 Alsedo Lorenzo e Hijos — Ecommerce

Plataforma de comercio electrónico para un negocio de La Plata. Desarrollo del catálogo, la experiencia de compra y las herramientas de administración.

- Catálogo con búsqueda, filtros y paginación.
- Carrito y gestión de pedidos.
- Administración de productos y permisos por roles.
- Importación de productos mediante archivos CSV y Excel.
- Gestión de imágenes con Cloudinary.

**Stack:** Next.js 14 · Tailwind CSS · Prisma · PostgreSQL · Cloudinary · Railway.

[Visitar sitio](https://alsedolorenzo.com)

---

### 📅 Bby Nails — Plataforma web de turnos

Sistema de reservas para un salón de uñas, con herramientas para que las clientas reserven y el negocio organice su agenda.

- Reservas online y pago de seña mediante Mercado Pago.
- Validaciones de disponibilidad para evitar superposición de turnos.
- Calendario administrativo con vistas de mes, semana y día.
- Reprogramación de turnos mediante arrastrar y soltar.
- Filtros por empleado e identificación mediante colores.
- Gestión de servicios y clientes.
- Acceso administrativo mediante sesión con cookies.

**Stack:** Next.js 14 · React · Tailwind CSS · FullCalendar · Prisma · PostgreSQL · Mercado Pago.

---

### 📱 Bby Nails — Aplicación Android

Primera versión del sistema de turnos, desarrollada como aplicación móvil. Fue el punto de partida para la evolución del proyecto hacia una plataforma web.

- Reservas en intervalos de 15 minutos.
- Seña del 40 % mediante Mercado Pago.
- Calendario y gestión de clientas y servicios.
- Almacenamiento de información en Firebase / Firestore.

**Stack:** Java · Android Studio · Firebase · Firestore · Mercado Pago.

## 🧪 Proyectos en desarrollo y exploración

Estos proyectos reflejan líneas de trabajo y prototipos. Su alcance y estado evolucionan durante el desarrollo.

### 📆 TurnoExpress — Reservas para distintos rubros

Proyecto de turnera adaptable a diferentes negocios y servicios. Entre los casos de uso explorados está la organización de turnos para un servicio municipal de zoonosis.

**Foco:** disponibilidad horaria, cupos y adaptación de las reservas a cada actividad.

### 📰 Sesgómetro — Análisis de noticias con IA local

Proyecto exploratorio, inicialmente llamado Neutralia, para analizar sesgos en noticias mediante modelos de lenguaje ejecutados localmente.

**Tecnologías exploradas:** Python · Ollama · Qwen3:8B.

### 🎨 ISoft Colors — Colorimetría

Proyecto de software de colorimetría orientado al contexto de una pinturería, con trabajo de identidad visual propio.

**Foco:** herramientas digitales aplicadas al rubro de pinturas.

### 📖 Pokédex para una campaña de rol

Diseño de una herramienta web con estética de Pokédex para acompañar una campaña de rol ambientada en Pokémon.

**Objetivo:** permitir que cada jugador consulte los Pokémon de su aventura y la información relevante durante las partidas.

### 🎤 NO ERA PARA TANTO! — Comedia multijugador

Concepto y planificación de un videojuego en Godot 4 basado en un show de stand up entre amigos.

- Un jugador interpreta al comediante usando su micrófono real.
- El resto participa como público y seguridad.
- Votación al finalizar cada ronda.
- Rotación de roles entre los participantes.

**Foco de diseño:** interacción por voz, humor emergente y dinámica social.

### 👻 Terror en una escuela — Proyecto en Godot

Proyecto de exploración de terror ambientado en un colegio, con un conserje fantasma y herramientas de investigación paranormal.

**Trabajo explorado:** escenarios, ambientación, objetos interactivos, equipamiento de investigación e interfaz.

### ⚔️ Roguelite de fantasía oscura — Diseño inicial

Concepto para un juego de un solo jugador en Godot, con combate de acción inspirado en Hades y una ambientación de fantasía oscura y terror.

**Estado:** definición del concepto y planificación del desarrollo.
